# Changelog

## 0.3.2 — Minimal menu

- Menu bar now contains only connection status, Enable Multiplayer, and Quit.
- Enable Multiplayer is disabled while connected; setup guidance uses the same wording.

## 0.3.1 — Simpler welcome

- Removed the extra network, capacity, and host-permissions paragraph from the welcome panel. Details remain in the documentation.
- Included the simplified README and kept installer links pointed at the current public script.

## 0.3.0 — Public preview

- Native Codex chat sharing for one host and four guests over a local network.
- Explicit invitations, pairing-code confirmation, revocation, and host-owned agent execution.
- Native profile avatars, subtle message-corner badges, typing indicators, images, and focused-chat unread handling.
- Wi-Fi address refresh, stale-device expiry, connection progress, and visible errors.
- Drag-to-Applications DMG, architecture-labeled downloads/checksums, custom app icon, first-run setup, local help, and diagnostic menu actions.
- MIT license, public security/installation documentation, and CI checks.

This preview uses private Codex interfaces and is ad-hoc signed, not notarized. LAN only; guest-network client isolation is not bypassed. Five-person coverage uses isolated UI fixtures, not five physical Macs.
