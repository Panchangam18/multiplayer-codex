Unofficial · Experimental · LAN only

One Codex chat.
A few more people.

Invite up to four collaborators into your existing chat. Keep the native composer, agent, and conversation. No extra account or relay server.

Install on both Macs

  1. Use macOS 14 or newer and an installed Codex desktop app. Download the installer matching your Mac's architecture from GitHub Releases.
  2. Open the disk image, drag Multiplayer Codex to Applications, then eject the disk image. Launch the installed app, not the copy inside the disk image.
  3. A people icon appears in the menu bar. Choose Connect to Codex. The same button becomes Disconnect to Codex when connected. If Codex needs to reopen, finish active agent work and confirm the restart. Saved chats are preserved.
  4. Allow local-network access if macOS asks. Both devices must be on a network that permits device-to-device traffic. Many guest networks intentionally block this.

Preview download: the initial release is ad-hoc signed, not Developer ID signed or notarized. macOS may block it. Building from source is available. If you deliberately trust the downloaded build, follow Apple's per-app approval instructions; do not disable Gatekeeper globally or bypass malware warnings.

Share a chat

  1. Right-click an idle, local chat in Codex's sidebar and choose Multiplayer.
  2. Select a nearby person. Compare the six-digit pairing code on both screens before the recipient accepts.
  3. Use the normal chat. Other people's messages have their profile avatar in the corner; hover for their name. Typing indicators show activity, never unsent draft text.
  4. Open Multiplayer again to remove someone or end sharing. Done closes the sheet without ending the session.

The host owns execution. Everyone's prompts use the host's Codex account, tools, files, and existing permissions. This is not a sandbox. Invite only people you trust. Removing access cannot erase history already received.

If something isn't working

  • No nearby devices: open the companion on both Macs, allow local-network access, and wait a few seconds. Try a private network if guest Wi-Fi isolates devices.
  • Connecting fails: ensure the other Mac is awake and re-invite after changing networks. The sheet displays connection errors.
  • Unsupported Codex build: this adapter depends on private interfaces. Check release compatibility notes; don't replace or modify Codex's app bundle.
  • Need diagnostics: open ~/Library/Application Support/Multiplayer Codex/companion.log. Review and redact logs before sharing; never publish device keys or transcripts.

Update or uninstall

Quit only Multiplayer Codex before replacing its app with a newer release, then reopen it and re-invite collaborators. To uninstall, quit the companion and move it to the Trash. Quit and reopen Codex normally to disable the localhost integration port. Optional pairing identities and author metadata remain in ~/Library/Application Support/Multiplayer Codex; deleting that folder resets them. Your saved Codex chats are separate and remain untouched.
